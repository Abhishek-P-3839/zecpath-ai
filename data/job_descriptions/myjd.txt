JOB TITLE: Junior Software Engineer
DEPARTMENT: Engineering
LOCATION: Kochi, Kerala / Hybrid
EMPLOYMENT TYPE: Full-Time
REPORTS TO: Engineering Manager

ABOUT THE ROLE
We are looking for a Junior Software Engineer to help build, test, and maintain web applications. You will work closely with senior developers, designers, and product managers to ship reliable features.

KEY RESPONSIBILITIES
- Write clean, maintainable, and well-tested code for frontend and/or backend features.
- Fix bugs, resolve performance issues, and support production deployments.
- Collaborate with team members on code reviews, sprint planning, and technical documentation.
- Follow version control workflows and security best practices.

REQUIRED QUALIFICATIONS & SKILLS
- Bachelor's degree in Computer Science, IT, or equivalent practical experience.
- 0 to 2 years of experience with at least one programming language (e.g., JavaScript/TypeScript, Python, Java, or C#).
- Basic understanding of relational or non-relational databases and REST APIs.
- Familiarity with Git and basic debugging tools.
- Strong problem-solving skills and clear written communication.

PREFERRED SKILLS
- Experience with modern web frameworks (e.g., React, Node.js, Django, or Spring Boot).
- Basic familiarity with cloud platforms or containerization (e.g., AWS, Docker).

COMPENSATION & BENEFITS
- Competitive salary based on experience and skill level.
- Paid time off, statutory benefits, and learning opportunities.

HOW TO APPLY
Send your resume and a link to your GitHub or portfolio to careers@example.com with the subject line "Junior Software Engineer Application".
